# Security policy

Jarvis can execute tools and access local information, so security reports are
taken seriously.

Please do not disclose a suspected vulnerability in a public issue. Use
GitHub's private vulnerability reporting feature for this repository instead.
Include the affected version or commit, reproduction steps, impact, and any
suggested mitigation. Avoid including real credentials or personal data.

Until version 1.0, security fixes are applied to the latest code on `master`.
